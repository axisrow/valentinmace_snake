# 🐍 Обучение змеи в Google Colab

Этот репозиторий теперь включает готовый ноутбук для Google Colab, который позволяет обучить нейронную сеть играть в змейку без установки зависимостей на локальный компьютер.

## 🚀 Быстрый старт

### Вариант 1: Открыть напрямую в Colab

1. Перейдите на GitHub: https://github.com/valentinmace/snake
2. Найдите файл `Snake_Training_Colab.ipynb`
3. Нажмите на кнопку "Open in Colab" (если доступна) или скопируйте содержимое

### Вариант 2: Загрузить файл

1. Скачайте файл `Snake_Training_Colab.ipynb` из этого репозитория
2. Откройте [Google Colab](https://colab.research.google.com/)
3. Нажмите `File → Upload notebook`
4. Выберите скачанный файл

### Вариант 3: Импорт из GitHub

1. Откройте [Google Colab](https://colab.research.google.com/)
2. Нажмите `File → Open notebook`
3. Выберите вкладку `GitHub`
4. Вставьте URL репозитория или найдите файл `Snake_Training_Colab.ipynb`

## 📋 Содержание ноутбука

Ноутбук включает следующие разделы:

1. **Установка зависимостей** - автоматическая установка всех необходимых библиотек
2. **Адаптация кода** - создание версий файлов, совместимых с Colab (без pygame)
3. **Запуск обучения** - генетический алгоритм с настраиваемыми параметрами
4. **Визуализация прогресса** - графики улучшения результатов по поколениям
5. **Скачивание моделей** - сохранение обученных весов для локального использования
6. **Тестирование** - проверка качества обученной модели

## ⚙️ Параметры обучения

В ноутбуке вы можете настроить:

- `POPULATION_SIZE` - размер популяции (рекомендуется: 500-1000)
- `GENERATIONS` - количество поколений (рекомендуется: 20-100)
- `crossover_method` - метод скрещивания ('weight', 'neuron', 'layer')
- `mutation_method` - метод мутации ('weight', 'neuron')

## 🎯 Что делает генетический алгоритм?

1. Создает популяцию нейронных сетей со случайными весами
2. Каждая сеть играет в змейку и получает оценку (fitness)
3. Лучшие сети отбираются как родители
4. Создаются новые сети через скрещивание и мутацию
5. Процесс повторяется много поколений

## 📊 Система зрения змеи

Нейронная сеть получает на вход **21 параметр**:
- Змея "видит" в 8 направлениях (↑↗→↘↓↙←↖)
- Для каждого направления: расстояние до стены, до еды, до своего тела

**Выходы (3 нейрона):**
- Повернуть налево
- Идти прямо
- Повернуть направо

## ⏱️ Время обучения

- **20 поколений, 500 особей**: ~10-20 минут
- **50 поколений, 1000 особей**: ~1-2 часа
- **100 поколений, 1000 особей**: ~3-5 часов

*Время зависит от типа Runtime в Colab (CPU/GPU)*

## 💡 Советы для лучших результатов

1. **Используйте GPU Runtime**:
   - `Runtime → Change runtime type → GPU`
   - Ускорит вычисления numpy

2. **Увеличьте количество поколений** для лучшего обучения

3. **Экспериментируйте с параметрами**:
   ```python
   # Пример настройки
   gen = GeneticAlgorithm(
       population_size=1000,
       generation_number=50,
       crossover_method='neuron',
       mutation_method='weight'
   )
   ```

4. **Сохраняйте промежуточные результаты**:
   - Ноутбук автоматически сохраняет лучшую модель каждого поколения
   - Файлы: `gen_N_best_weights.npy` и `gen_N_best_biases.npy`

## 📥 Использование обученных моделей локально

После обучения в Colab:

1. Скачайте файлы весов (последний шаг ноутбука автоматически скачает их)
2. Поместите их в папку `saved/` в локальной копии репозитория
3. Запустите локально с pygame:

```python
from game import Game
from neural_network import NeuralNetwork

net = NeuralNetwork()
net.load('saved/gen_20_best_weights.npy', 'saved/gen_20_best_biases.npy')

game = Game()
game.start(display=True, neural_net=net)
```

## 🐛 Возможные проблемы

### Ошибка "Session crashed"
- Уменьшите `POPULATION_SIZE` или `GENERATIONS`
- Colab имеет ограничения по памяти и времени выполнения

### Медленное обучение
- Используйте GPU Runtime
- Уменьшите размер популяции
- В коде уже добавлен лимит итераций (1000) для предотвращения зависания

### Отключение от Colab
- Бесплатная версия Colab отключается через ~12 часов
- Используйте Colab Pro для длительных тренировок
- Периодически проверяйте прогресс
